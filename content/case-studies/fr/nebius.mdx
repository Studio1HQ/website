Studio1 partnered with **Nebius** to grow developer adoption of Nebius Token Factory. The aim was simple: get developers building on Token Factory, not just reading about it.

## At a glance

* **Client:** Nebius Token Factory, a platform to build, fine-tune, and run open models at production scale
* **Services:** launch demos, technical content and video, framework integrations, open-source examples, workshops, and community distribution
* **Results:** a launch demo with **588K views**, a build article with **124K+ views**, a **16K+ star** open-source library, and **29 integrations**

## About Nebius

[**Nebius**](https://nebius.com) builds cloud infrastructure for AI teams. **Nebius Token Factory** is its platform to build, fine-tune, and run open models at production scale, behind an OpenAI-compatible API.

Token Factory's audience is developers choosing where to run and serve models, and they decide by trying things, not by reading positioning.

## The challenge: turning developer attention into hands-on exploration

Token Factory competes for developers who choose by building. Nebius needed developers to find the product where they already work, and to see proof they could run:

* Presence inside the frameworks and gateways developers already use
* Working examples built on Token Factory models
* Hands-on events that end with the product in use
* Visibility at every launch and new model

## The outcomes

### 1. Launch demos that developers shared

For new model launches on Token Factory, we built interactive demos that show what each model can do, and Nebius shared them with its own audience.

One of them, a 3D explainer that takes any machine apart piece by piece, reached **588K views** on Nebius's X account in under two weeks.

## The results

* **588K views** on a launch demo Nebius shared on X
* **124K+ views** on a Token Factory build article
* **16K+ GitHub stars** on the open-source examples library, with two GitHub trending appearances
* **29 integrations** across frameworks, gateways, and developer tools
* **Hundreds of thousands of Reddit views** across community posts
* Hands-on product use at workshops and meetups

Figures were checked in November 2026 or are those reported by the platforms at the time.

## Why it worked

The work covered the whole path a developer takes: finding Token Factory inside a familiar framework, seeing it work in an example, building with it at an event, and meeting it again at each launch.

Speed mattered too. A new model is news for a few days, so the demos were ready while developers were paying attention.

For an infrastructure product, that continuity is the point. Developers choose by building, so everything we shipped was designed to get them building.
