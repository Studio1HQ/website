Studio1 is looking for a DevRel Engineer with a GenAI and AI-agent background who can build, explain, and ship developer-facing work across AI, devtools, SaaS, and open-source products. This is an engineering-first DevRel role for someone who can learn new tools fast, create useful demos, write clearly, and turn implementation work into tutorials and walkthroughs.

This is not a generic content or social media role. The core work is technical: building projects, understanding developer products, writing useful tutorials, and creating videos that help developers understand new tools.

## What you will do

You will work with the Studio1 team on technical DevRel work for Studio1, Raah, AssetSnip, and client projects.

- Build AI-agent demos, GenAI workflows, sample apps, integrations, technical experiments, and prototype repos around developer products.
- Learn new frameworks, SDKs, APIs, model providers, agent tools, and devtool workflows quickly enough to create accurate examples.
- Write technical blogs, tutorials, docs, guides, project walkthroughs, and launch content from real implementation work.
- Record technical videos, demo walkthroughs, product explainers, and tutorial-style content when a topic needs video support.
- Turn technical research into clear content ideas, outlines, scripts, posts, and implementation plans.
- Coordinate with Studio1's design, video, and social team so supporting assets, clips, visuals, and distribution pieces stay technically accurate.
- Support developer-facing campaigns with code examples, GitHub repos, technical angles, and practical developer context.
- Support developer/community conversations or partner calls when a project needs technical context.

## What we are looking for

You should be comfortable writing code, explaining technical ideas, and learning unfamiliar tools without waiting for step-by-step instructions.

- 1+ year of experience in DevRel engineering, GenAI engineering, AI-agent projects, technical content, open source, or a similar technical role is preferred.
- Previous work with companies, clients, startups, open-source projects, or developer communities is a strong plus.
- You can build practical demos around AI agents, LLMs, RAG, tool calling, model APIs, workflows, SDKs, auth, devtools, SaaS, or infrastructure topics.
- You have hands-on GenAI experience and can move beyond generic web apps or wrapper demos.
- You have creative instincts for turning technical ideas into demos, videos, tutorials, or social posts developers would actually want to click.
- You can write clear technical blogs, tutorials, docs, or guides from real implementation work.
- You are comfortable planning, recording, and explaining technical demos or walkthrough videos with clear structure and useful developer context.
- You can communicate with developers, understand feedback, and represent technical work clearly when needed.
- You can learn new frameworks, tools, or stacks quickly and turn that learning into useful developer-facing material.
- You can share proof of work such as GitHub repos, live demos, technical blogs, docs, videos, tutorials, open-source work, or shipped developer content.

## Why join

You will work on real developer products and client projects across AI, agents, devtools, open source, and SaaS. You will get ownership to build demos, write, record, experiment, and create work that developers can actually use.

## Role details

This is a full-time remote role for India-based candidates. Best fit: DevRel engineers, GenAI builders, AI-agent developers, technical creators, or strong engineers who can code, explain, and ship developer-facing work.
