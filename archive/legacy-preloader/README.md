# Legacy preloader (archived)

The original night-black intro preloader: `components/preloader.tsx` and its
styles from `app/globals.css` (`preloader.css`). The live preloader now uses
the paper palette by default and also runs on inner pages with the page name.

To restore, copy `components/preloader.tsx` back and replace the
"Intro preloader" block in `app/globals.css` with `preloader.css`.
