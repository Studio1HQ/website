# Legacy About page (archived)

The pre-paper version of the About page (dark NightHeader hero, glass cards),
kept for reference while the paper design is live. Not routed: Next.js only
serves pages under `app/`.

Paths mirror the repo. To restore, copy the files back over the live ones:

- `app/(site)/about-us/page.tsx` -> `app/(site)/about-us/page.tsx`
- `components/about-us/*.tsx` -> `components/about-us/`

`components/shared/night-header.tsx` (used by the old hero) is unchanged.
