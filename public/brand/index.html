About Studio1 Sans

Studio1 writes for developers and the teams who build for them. Our type had to read like good documentation: clear first, never decorative.

We set everything in Studio1 Sans, our own cut of Inter, using only Regular and Medium, with tight -0.03em letter spacing. Hierarchy comes from size, not from bold.

One typeface carries everything, from headlines and UI to labels and numbers. Only code blocks switch to the reader's own monospace font, so there's nothing extra to load.

Everything here, from fonts and tokens to the logo and templates, ships as one kit that any designer, developer or AI tool can follow.

Type does the work. Everything else stays quiet.

Logo

The mark and the wordmark.

The gradient mark with the wordmark is the main logo: use it by default, on paper and white. On dark backgrounds, use the dark-mode logo: the same gradient mark with white cut-outs and a white wordmark. Use the white or black mark only where colour can't be used. Keep clear space of a quarter of the mark's height around it, and never show it smaller than 16px.
